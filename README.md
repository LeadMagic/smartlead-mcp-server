# Smartlead MCP Server: Archived Integration by LeadMagic

This archived TypeScript project connects Model Context Protocol (MCP) clients to Smartlead email campaign workflows. It is retained as historical source code from LeadMagic.

**Status: archived and not actively maintained.** Client compatibility, tool coverage, and third-party API behavior are not guaranteed to match current services.

## Current LeadMagic integrations

For LeadMagic B2B enrichment, use [hosted MCP setup](https://leadmagic.io/docs/mcp/setup?utm_source=github&utm_medium=readme&utm_campaign=smartlead-mcp-server&utm_content=readme-current-leadmagic-integrations), the [Claude Code plugin](https://github.com/LeadMagic/leadmagic-claude-plugin), or the [Cursor plugin](https://github.com/LeadMagic/leadmagic-cursor-plugin). These connect to LeadMagic and do not replace Smartlead campaign management.
